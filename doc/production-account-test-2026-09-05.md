# 《雾港最后一盏灯》正式账号测试与修复总结

> 日期：2026-09-05
>
> 对象：AlterU 迁移后的正式游戏、同 UUID Story Session Worker、服务器 Prolog 规则服务
> 本文不记录真实账号 ID、Telegram 启动参数、服务令牌或调试凭据。

## 1. 本轮目标

本轮不只验证前端能打开，而是验证迁移后的正式用户路径是否真正贯通：

1. 平台实时用户身份能进入游戏；
2. 每个确定性行动由 Story Session 和 Prolog 共同完成，而不是前端伪造结果；
3. 存档、恢复、重放、物品消耗、人物首次登场和章节完成能稳定工作；
4. 找出只在 AlterU 正式宿主中才会出现的集成问题，修复后重新发布。

## 2. 正式用户路径结果

使用迁移后的正式 AlterU 游戏卡片进行了如下实测：

- 首次进入、真实用户名与头像显示：通过；
- 前置条件不足时的结构化拒绝：通过，零错误写入；
- 选项快速连点：通过，物品只获得一次；
- 工具袋中风暴提灯动态灯油：通过，使用后正确显示剩余 `2`；
- 退出后重新进入：通过，会话、地点、数值、物品和可执行选项恢复一致；
- 安雅首次登场：通过，先显示可辨认外形与动作，再给出名字和意图，之后才进入人物面板；
- 十个确定性行动完整通关：通过，最终镇定 `4`、港区信任 `3`、信号稳定 `6`；
- 终局物品事务：通过，绝缘铜线与聚光镜片各消耗一次；
- 章节完成后再次进入：通过，完成结果和最终存档持久化。

## 3. 发现与修复

### 已修复：平台游玩事件缺失

**现象**：完成正式游玩并退回 AlterU 游戏卡片后，卡片仍显示 `0 Played`。

**确认的集成缺口**：这款 RPG 已接入平台用户资料和 Story Session，但漏掉了平台 `/note/aigram/ai/game/record/play` 事件上报。这是需要修复的平台集成问题。平台已确认 Played 没有用户去重设计，卡片数字不立即变化应解释为统计缓存或刷新延迟。

**修复**：

- 从项目共享 runtime 合同接入 `useGameEvent`，没有自行重写桥接协议；
- 玩家明确点击“进入”或“继续游戏”时，上报一次 `story_play`；
- 页面自动加载、存档后台恢复和普通回合不上报，防止重复计数；
- 平台外访客不上报；
- 新增浏览器回归，校验事件名、游戏 UUID、首次进入、存档恢复和访客抑制。

**正式复验**：修复版发布到原 UUID 地址后，不重新迁移也会被 AlterU 直接读取。卡片已由 `0 Played` 变为 `6 Played`；同一账号再次点击“继续游戏”后短时内仍为 `6`，这是卡片统计缓存/延迟刷新，不是用户去重。

### 已排除：提灯指标与危险提示

- “剩余灯油”位于物品详情的属性区，中间图鉴占用一屏；继续滚动后可见，不是数据丢失。
- 下码头的“危险征兆”来自 Cartridge 对 `descend-lower-quay` 的明确 `dangerPolicy: advance`，是本章的可控环境压力，不是模型擅自增加的事件。

### 观察项：一次测试环境竞态

新增事件测试首次运行时，会话列表在等待到 version `1` 后的立即二次读取曾短暂返回 version `0`。原命令立即重跑、新增完整测试后重跑以及全量多轮套件均未再复现；当前记为测试环境观察项，不作为线上数据回退结论。如后续再现，必须保留连续目录响应与事件 cursor 证据后处理。

## 4. 自动化回归

- 完整多轮套件：`26` 个命令全部通过；
- 故障、并发、持久化、目录和迁移：连续 `3` 轮通过；
- 用户桥接：首次进入、恢复、资料、云端镜像、双用户隔离、跨用户读取拒绝通过；
- 事件桥接：进入与恢复各一次、正确 UUID、平台外抑制通过；
- 视觉：`390×844` 中文主路线、`320×568` 英文路线、44 px 触控目标与无横向溢出通过；
- 发布安全：源码/产物凭据、固定后端 URL、裸 `/api` 和自托管存储隔离审计通过；
- 依赖审计：生产依赖 `0` 个已知漏洞。

## 5. 已知边界与后续

- 本轮只有一个真实 AlterU 账号完成端到端游玩；双用户隔离使用完整宿主桥接模拟和真实 Durable Object 实现测试。
- 当前实验仍使用宿主实时用户 ID 派生 owner，尚不是服务端签名的短时身份声明；这是将服务器能力开放给其他创作者前必须解决的安全门禁，不阻断本次限定实验。
- 同 UUID 部署地址的更新会自动进入 AlterU 线上游戏，无需重复迁移。本轮已确认新版本、Played 卡片统计与原 UUID 存档恢复均正常。
